# Contributing

Thanks for contributing to wisdom-culture-travel-assistant.

## 行为准则 / Code of Conduct

本项目采用 [贡献者公约](CODE_OF_CONDUCT.md)。所有参与者都应遵守其中规定，包括不可滥用声明和商用条款。

## 贡献者列表 / Contributors

欢迎通过 Pull Request 提交贡献。如果你的 PR 被合并，你可以选择将你的名字加入 README 的贡献者列表。

## Pull Request Requirements

1. Base the work on the latest code.
2. Keep the PR focused — do not mix unrelated features.
3. Run local validation before submitting.
4. Provide evidence for user-facing features.

PRs that skip these requirements may be blocked until the missing information is provided.
